# Curriculum Vitae & Mini Style Guide

Project ini dibuat untuk memenuhi tugas Praktikum Desain Web Pertemuan 3. Project terdiri dari halaman Curriculum Vitae (CV) dan Mini Style Guide sebagai panduan visual desain CV.

## 1. Curriculum Vitae

Halaman Curriculum Vitae dibuat menggunakan HTML dengan desain modern, minimalis, dan profesional. Tampilan menggunakan kombinasi warna biru tua, biru, ungu, cyan, dan hijau.

Informasi yang ditampilkan meliputi:

- Profil pribadi
- Pendidikan
- Keahlian
- Kontak

Desain CV menggunakan beberapa komponen, seperti header berwarna biru tua, card dengan latar belakang putih, serta aksen warna pada setiap bagian informasi.

## 2. Mini Style Guide

Mini Style Guide dibuat sebagai panduan visual yang menjelaskan elemen desain yang digunakan pada halaman Curriculum Vitae.

### Style Guide

- **Font utama:** Poppins
- **Font alternatif:** Arial, sans-serif
- **Warna utama:** `#172554` (Navy)
- **Warna sekunder:** `#3B82F6` (Biru)
- **Warna aksen ungu:** `#8B5CF6`
- **Warna aksen cyan:** `#06B6D4`
- **Warna aksen hijau:** `#10B981`
- **Heading 1:** 32px
- **Heading 2:** 24px
- **Body text:** 16px
- **Line height:** 1.8

### Komponen Desain

- **Card:** Menggunakan latar belakang putih, sudut membulat, dan bayangan tipis.
- **Warna heading:** Menggunakan warna navy dan biru untuk memperjelas hierarki informasi.
- **Aksen warna:** Menggunakan garis pada bagian atas card dan variasi warna untuk membedakan elemen desain.
- **Background:** Menggunakan warna abu-abu kebiruan agar card terlihat lebih menonjol.

## 3. Teknologi yang Digunakan

- **HTML5:** Untuk menyusun struktur halaman CV dan Mini Style Guide.
- **CSS3:** Untuk mengatur warna, font, ukuran teks, jarak, card, dan tampilan halaman.

## 5. Cara Menjalankan

1. Pastikan seluruh file HTML, CSS, dan gambar berada pada folder yang sesuai.
2. Buka file `TugasPertemuan3_1.html` melalui browser untuk melihat halaman Curriculum Vitae.
3. Buka file `TugasPertemuan3_2.html` melalui browser untuk melihat halaman Mini Style Guide.
4. Ambil screenshot dari kedua halaman setelah tampil dengan benar, lalu simpan ke folder `images/` sesuai nama yang tercantum pada README.
